Este error persistente TypeError: 'NotImplementedType' object is not iterable dentro del analizador CSS de xhtml2pdf se debe a una incompatibilidad estricta con Python 3.14 (la versión moderna que estás utilizando en tu entorno virtual). El parser de CSS antiguo que utiliza xhtml2pdf internamente (cssParser.py) realiza una validación de selectores que en Python 3.14 devuelve un tipo no iterable al procesar las sub-etiquetas @bottom-right y @bottom-left de las páginas de ReportLab. La Solución Definitiva Para solucionar esto sin tener que degradar tu versión de Python, debemos estructurar el PDF utilizando el estándar clásico de xhtml2pdf / ReportLab. En lugar de usar CSS moderno dentro de @page, utilizamos etiquetas estructurales especiales de ReportLab como metidas en una tabla fija o un contenedor inferior, removiendo por completo las propiedades conflictivas del bloque @page.
